## 📝 Обновлённые файлы

### 1. `server.js` (+32 строки)
**Что логгируется:**
- `[SERVER STARTED]` — старт сервера на порту 8090
- `[SERVER ERROR]` — ошибка декодирования URL
- `[SERVER ERROR]` — запрещённый доступ (403 Forbidden)
- `[SERVER ERROR]` — файл не найден (404 Not Found)
- Полный stack trace при критических исключениях

**Пример вывода:**
```
[SERVER STARTED] [2026-10-01T17:31:12.882Z] Oncology US Analytics: http://127.0.0.1:8090
[SERVER INFO] Логи ошибок выводятся в консоль разработчика
```

---

### 2. `app.js` (+8 строк)
**Что логгируется:**
- `[CHARTS]` — загрузка Chart.js (успех/ошибка)
- `[DATA SOURCE]` — переключение источников данных
- `[RENDER ERROR]` — попытка рендера без данных
- `[YEAR AGG ERROR]` — невозможность агрегации по годам

**Пример вывода:**
```
[CHARTS INFO] Chart.js загружен успешно, графические контролы активны
[DATA SOURCE] Переключение режима: synthetic
```

---

### 3. `data-source.js` (+6 строк)
**Что логгируется:**
- `[API] HTTP <status>` — ошибка fetch к API
- `[DATA ERROR]` — валидация записей данных
- `[VALIDATION]` — отсутствующие поля в записи
- `[AUTO-FALLBACK]` — переключение на демо-данные

**Пример вывода:**
```
[API] HTTP 500 (https://example.com/api)
[DATA SOURCE] Загрузка данных из ClinicalTrials.gov
```

---

### 4. `map.js` (+12 строк)
**Что логгируется:**
- `[MAP INFO]` — загрузка топологии США
- `[MAP WARNING]` — неудача загрузки топологии → tile-grid карта
- `[MAP ERROR]` — ошибка загрузки d3 или topojson-client
- `[MAP FALLBACK]` — использование fallback карты

**Пример вывода:**
```
[MAP INFO] Загрузка топологии США: https://cdn.jsdelivr.net/npm/us-atlas@3/states-10m.json
[MAP WARNING] Попытка загрузки топологии США неудачна, используется tile-grid карта
```

---

## 📖 Руководство по использованию

### Для разработчиков:
1. Откройте DevTools (**F12**) → вкладка **Console**
2. Запустите http://127.0.0.1:8090/index.html
3. Все ошибки будут отображаться с префиксами:
   - `[SERVER ERROR]` — серверные ошибки
   - `[CHARTS ERROR]` — проблемы с графиками
   - `[DATA LOAD ERROR]` — ошибки загрузки данных
   - `[MAP ERROR]` — проблемы с картой

### Для отладки:
Используйте фильтр в консоли: `ONCO-*` для отображения только логов приложения.

### Для продакшена:
Замените `console.error` на production logger при необходимости.
