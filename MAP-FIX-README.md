# Исправление отображения штатов на карте США

## Проблема
Карта США с тепловыми значениями не отображала штаты — была видна только пустая область или tile-grid без данных.

## Причины
1. **Асинхронная загрузка ресурсов**: topoloogy США загружалась через `fetch()` из CDN асинхронно
2. **Отсутствие проверки топологии**: код пытался отрисовать SVG даже когда топология не была загружена
3. **Пустая карта при отсутствии данных**: не было стартовой заглушки с tile-grid

## Исправления (в map.js)

### 1. Улучшенная проверка загрузки в `tryRender()`
```javascript
// Теперь проверяем:
// - libsReady (d3 и topojson загружены)
// - window.d3 (библиотека доступна)
// - topoRawCache (топология загрузилась через fetch)
// Если ресурсы не готовы — показываем tile-grid как заглушку
```

### 2. Улучшенная обработка ошибок
```javascript
.catch(function (err) { 
  console.error('[MAP ERROR] Парсинг топологии неудачен:', err.message, '→ tile-grid карта');
  renderTiles(box); done(); 
})
```

### 3. Добавлена проверка наличия топологии
```javascript
} else if (!topoRawCache) {
  console.error('[MAP WARNING] Топология США не загружена (fetch неудачно), используем tile-grid карту');
  renderTiles(box);
  done();
  startLibs();
}
```

### 4. Улучшенная отладка в `render()`
```javascript
console.error('[MAP DATA] Значения для', valueCount, 'штатов (null:', hasNulls + ')');
console.error('[MAP RENDER] min:', state.min, 'max:', state.max);
```

### 5. Подключён map.js в index.html
Убрана закомментированная строка — карта теперь обязательна для отображения.

## Тестирование

### Основной файл: `test-map-fix.html`
- Использует тестовые данные (10k–50k случайных значений)
- Показывает калифорнию (CA) по умолчанию
- Выводит отладочную информацию в консоль

### Запуск:
```bash
# Через локальный сервер (рекомендуется):
npx http-server . -p 8080

# Открыть:
http://localhost:8080/test-map-fix.html
```

### Проверка на production:
- Откройте `index.html` в браузере
- Карту нужно открывать через HTTP(S) (не file://), так как использует fetch к CDN

## Fallback: Tile-grid карта
Если топология США не загрузилась (отсутствует интернет или ошибка CDN), используется tile-grid карта — квадратная сетка 12×8 с обозначением штатов буквами.
