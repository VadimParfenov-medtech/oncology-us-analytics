# Тёмная тема (Dark Mode) 🌙

Онакологический аналитический дашборд США теперь поддерживает переключение между светлой и тёмной темами.

## Как включить

Нажмите кнопку **🌙/☀️** в правом верхнем углу заголовка. Тема сохраняется в памяти браузера.

## Цветовая палитра

| Элемент | Светлая тема | Тёмная тема |
|---------|--------------|-------------|
| Фон страницы | `#f1f5f9` (светло-серый) | `#0f172a` (тёмно-синий) |
| Карточки/блоки | `#ffffff` (белый) | `#1e293b` (тёмный серый) |
| Текст основной | `#0f172a` (тёмный) | `#f8fafc` (светлый) |
| Акцентный цвет | `#2563eb` (синий) | `#60a5fa` (светло-синий) |
| Границы | `#e2e8f0` (светло-серый) | `#334155` (серый) |
| Кнопка переключения | — | становится зелёной при тёмной теме |

## Текст на графиках в тёмной теме ✅

При переключении на тёмную тему **все текстовые элементы графиков** автоматически становятся белыми (`#f8fafc`):

### Что охватывает настройка:
- ✅ Заголовки графиков (Chart.js plugins.title)
- ✅ Подписи осей X и Y (scale titles)
- ✅ Значения в тултипах (tooltips)
- ✅ Легенды (legends)
- ✅ Сетки графиков (grids)

### Реализация:
1. **Глобальные настройки Chart.js** — при загрузке библиотеки настраиваются все дефолтные цвета для тёмной темы
2. **CSS селекторы** — специфичные стили для Canvas элементов с `!important`
3. **Observer API** — автоматическое обнаружение изменений атрибута `data-theme` и перерисовка графиков
4. **После-рендери обработка** — поиск заголовков по их текстовому содержимому (ключевые слова)

### Ключевые особенности:
- При переключении темы графики автоматически перерисовываются с новыми цветами
- Observer отслеживает изменения `data-theme` атрибута в реальном времени
- Поиск заголовков идёт по их текстовому содержимому (например, "Динамика: новые случаи по годам")

## Реализация

### HTML (`index.html`)
Добавлена кнопка переключения темы в заголовок:
```html
<button type="button" id="themeToggle" class="btn btn--ghost theme-btn">🌙</button>
```

### CSS (`style.css`)
- Определены переменные для обеих тем в `:root` и `[data-theme="dark"]`
- Все цвета используют CSS-переменные с авто-переключением
- Поддерживается плавный переход между темами
- Специальная стилизация для Canvas элементов Chart.js (тултипы, легенды)

### JavaScript (`app.js`)
- Автоматическое восстановление предпочтения при перезагрузке (`localStorage`)
- Индикатор кнопки меняется (🌙 → ☀️) при переключении темы
- Глобальные настройки Chart.js для цветов текста в зависимости от темы
- Автоперерисовка графиков при смене темы (через 250ms после клика)
- **Observer API** — автоматическая перерисовка при изменении атрибута `data-theme`

## Техническая информация

Реализована через CSS Custom Properties (CSS Variables) с атрибутом `data-theme="dark"`, что позволяет:
- Плавно переключать все цвета приложения
- Минимизировать количество дублирующихся стилей
- Легко вносить правки в цветовую схему

Глобальные настройки Chart.js применяются автоматически при загрузке библиотеки, обеспечивая белый текст на всех графиках независимо от конкретной конфигурации.

### Решение проблемы с заголовками графиков

Проблема: Chart.js использует динамически создаваемый DOM для заголовков, и CSS селекторы не всегда могут найти их по классам.

**Решение**: Комбинированный подход:
1. Глобальные настройки через `Chart.defaults.plugins.title.color`
2. CSS с множественными селекторами (по роли, атрибутам, тексту)
3. Observer API для отслеживания изменений темы в реальном времени
4. После-рендери обработка с поиском по текстовому содержимому

## Частые вопросы

### Заголовки графиков не меняют цвет на белый?
Убедитесь, что:
1. Тема действительно переключена (кнопка показывает ☀️)
2. График отрисован полностью (подождите 1-2 секунды после загрузки)
3. В консоли нет ошибок Chart.js

### Графики не перерисовываются при переключении темы?
Observer API автоматически отслеживает изменения атрибута `data-theme` и перерисовывает графики без необходимости нажимать кнопку снова.
