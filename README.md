# Онкологическая аналитика · США (2024–2026)

Веб-приложение (дашборд) для аналитики онкологических показателей по США:
фильтры **год / штат / тип рака / стадия**, KPI с дельтами, **тепловая карта США**,
срез **«мужчины/женщины»**, 6 графиков (Chart.js), сортируемая таблица и экспорт CSV.

Чистый vanilla JS + Chart.js + d3-geo. Сборки, бандлеров и зависимостей npm не требуется.

## Запуск

```bash
node server.js            # http://127.0.0.1:8090  (PORT=8091 node server.js — другой порт)
```

Либо просто открыть `index.html` двойным кликом (приложение работает и с `file://`,
но внешние API/карта требуют сети).

## Производительность загрузки

Демо-режим стартует без ожидания внешних ресурсов:

- **Библиотеки асинхронные.** Chart.js, d3 и topojson-client подтягиваются
  кодами `app.js` / `map.js` в фоне (раньше они стояли блокирующими `<script>`
  перед запуском приложения и задерживали его на ~500 КБ скачивания).
- **Прогрессивный рендер.** KPI, таблица и карта (tile-grid) рисуются сразу;
  графики появляются, как только подгрузится Chart.js (оверлей «Загрузка
  графиков…»), а карта автоматически перерисовывается в настоящую SVG,
  когда готовы d3 + топология.
- **Топология США prefetch-ится** фоном при запуске — параллельно с рендером.
- **Демо-датасет генерируется лениво** (6 120 записей, детерминированно,
  строится один раз при первом обращении — значения без изменений).
- **Один проход вместо ~150.** Все срезы (годы/типы/стадии/штаты) строятся
  единопассовой агрегацией `stats.js` — переключение фильтров заметно быстрее.

## Источники данных

Переключатель **«Источник данных»** в панели фильтров + `config.js` + URL-параметры.

| Режим | Что загружает | Когда |
|---|---|---|
| `synthetic` | Встроенный детерминированный датасет (`data.js`, 6 120 записей) | офлайн, демо, дефолт |
| `trials` | **Реальные данные** публичного API [ClinicalTrials.gov v2](https://clinicaltrials.gov/api) | активные/набирающие онкоиспытания в США, старт 2024–2026 |
| `wonder` | Официальная статистика **CDC WONDR / SEER-NPCR** от CDC и NCI | официальная онкостатистика США (SEER*Stat + NPCR) |
| `api` | Ваш REST API по контракту ниже | `config.js → apiUrl` |
| `auto` | `wonder` → `trials` → `api` → `synthetic` (по приоритету источников) | дефолт `config.js` |

URL-переопределение (приоритет выше `config.js`):

```
index.html?source=trials
index.html?source=wonder&api=https://wonder3.cdc.gov/api&apiName=CDC WONDR
index.html?source=api&api=https://host/oncology&apiName=Внутренний
```

При недоступности реального источника приложение показывает баннер с причиной
и автоматически откатывается на демо-данные (в режиме `auto`/`trials` с fallback).

### Адаптер ClinicalTrials.gov (`trials`)

- Запросы: `GET https://clinicaltrials.gov/api/v2/studies?query.cond=<тип>&filter.overallStatus=RECRUITING,ACTIVE_NOT_RECRUITING&pageSize=100&fields=NCTId,Phase,StartDate,Location` (+ `pageToken` для пагинации).
- Без ключа, с CORS — работает прямо из браузера.
- Маппинг: **тип рака** → `query.cond`; **штат** → `locations[].state` (США, англ. имена штатов → коды AL…WY/DC); **стадия** → фаза испытания (`PHASE1…4` → `I…IV`, `N_A` → `N/A`); **год** → год `StartDate` (2024–2026); «случаи» → число испытаний.
- Выборка: до 300 испытаний на тип (3 страницы × 100) — неполная перепись, о чём сообщает баннер.
- Смертность/выживаемость/стоимость/пол источник не предоставляет — соответствующие KPI/графики скрываются, появляются дополнительные KPI «Площадок в США» и «Штатов с данными».

### Ограничения CDC WONDR API (`wonder`)

- Прямой доступ к CDC WONDR API из браузера может быть ограничен CORS.
- **Решение**: Используйте прокси-сервер или backend для запросов к `https://wonder3.cdc.gov/api`.
- Или задайте свой прокси в `config.js → apiUrl` с префиксом: `index.html?api=https://your-proxy.com/wonder-api`.
- Маппинг:
  - **тип рака** → CONDITION (`breast cancer females`, `prostate cancer males` и т.д.);
  - **штат** → REGION_NAME (название штата на английском);
  - **стадия** → SEER_STAGE (0=in_situ, 1=local/regional, 2=regional, 3=distant, N/A);
  - **год** → YEAR (актуальные годы: 2023–2025);
  - **случаи** → CASES (новые случаи онкологических заболеваний).

### Контракт внешнего API (`api`)

`GET {apiUrl}` → `200 OK`, `application/json` (CORS открыт для браузера).

Либо объект `{"records": [...], "meta": {...}}`, либо просто массив записей:

```jsonc
[
  {
    "state": "CA",                  // код штата (AL…WY, DC) — обязательно
    "stateName": "Калифорния",      // необязательно
    "type": "breast",               // id типа — обязательно
    "typeName": "Рак молочной железы",
    "stage": "I",                   // I | II | III | IV (или любые свои)
    "year": 2024,                   // число — обязательно
    "newCases": 123456,             // число — обязательно (основная величина)
    "deaths": null,                 // число|null
    "survival5y": 91.2,             // число|null (%, 0–100)
    "costPerPatient": 85000,        // число|null (USD)
    "medianAge": 62,                // число|null
    "malePct": 99                   // число|null (%, 0–100)
  }
]
```

Правила:
- Измерения (годы, штаты, типы, стадии) выводятся **из записей** автоматически.
- Метрики с `null` корректно отображаются как «—»; KPI/графики скрываются,
  если метрика отсутствует во всём датасете.
- Опционально `{"meta": {"caseLabel": "новые случаи", "extraKpis": [{"label": "Площадок", "value": 42}]}}` —
  переопределение подписи основной величины и дополнительные KPI-карточки.
- Если штаты — `CA`, `NY`… и у них есть население, добавьте в ответ
  `{"meta": {"states": [{"code": "CA", "popM": 39.4}]}}` — тогда на карте
  станут доступны метрики «на 100 тыс. населения» (иначе приложение берёт
  встроенные оценки населения для знакомых кодов).

## Тепловая карта США

- Основной рендер: реальная карта штатов (d3-geo `geoAlbersUsa` + us-atlas
  TopoJSON с jsDelivr).
- Fallback: tile-grid карта (квадратная сетка штатов) — полностью офлайн,
  активируется, если d3/топология недоступны.
- Метрики: случаи/смерти (абс. и на 100 тыс.), выживаемость, стоимость —
  по наличию в источнике; переключатель в карточке.
- **Клик по штату = фильтр по штату** (повторный клик снимает), hover — tooltip.

## Ограничения

- Демо-режим — синтетические данные (детерминированные), 2026 год — проекция.
- Режим `trials` — выборка испытаний (не полн перепись); это данные о клинических
  исследованиях, а не об incidence-статистике пациентов.
- CDC WONDR API может требовать прокси-сервера из-за CORS ограничений.
- Для официальной онкостатистики (incidence/смертность/выживаемость по штатам)
  используйте CDC WONDER / SEER: подготовьте прокси и задайте его в `config.js → apiUrl`.
